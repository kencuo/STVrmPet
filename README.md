# VRM Pet（桌面桌宠）- SillyTavern 扩展

为每个角色绑定一个 `.vrm` 模型，并在页面右下角显示一个可拖拽、可走动、可互动的“桌面桌宠”。

> 位置：`SillyTavern-release/public/scripts/extensions/vrm-pet/`

## 功能

- 每角色绑定 VRM：在扩展设置里上传 `.vrm`，保存到服务器（`/api/files/upload`），并写入当前角色的 `extensions.vrm-pet` 字段
- 桌宠悬浮窗：右下角显示，可拖动，位置会记忆
- 桌面走动：窗口会在屏幕范围内来回走动（默认开启）
- 走路摆动：走动时原地走路（含手臂摆动 + **腿部/膝盖弯曲**的程序动画）
- 侧身朝向：走动时自动侧身（可调角度）
- 头部追踪/简化眼动：头/颈会轻微跟随鼠标
- 空闲动作/眨眼：无交互时随机动作与眨眼（需要模型支持相关表情）
- 摸头：点击头部附近触发“摸头反应”+ 爱心粒子
- 表情面板：开心/愤怒/无语/黑脸/恢复（优先用 VRM 表情，缺失时用覆盖层特效兜底）
- 桌宠聊天：独立聊天面板，记录保存到角色扩展字段（只保留最近一段避免膨胀）
- 气泡台词：桌宠在“桌宠聊天”里生成回复后，会在桌宠旁边短暂显示气泡
- AI 回复（填入输入框）：可用 `generateRaw()` 生成一段回复并填入 SillyTavern 主输入框（会自动去除 `<think>`/`<thinking>` 内容）

## 安装 / 启用

1. 将 `vrm-pet` 文件夹放到 `public/scripts/extensions/` 下（本项目已包含）
2. 启动 SillyTavern，进入 **扩展设置**，找到 **VRM Pet**
3. 勾选启用，然后为当前角色上传 `.vrm` 并绑定

## 使用说明

- 拖动：按住桌宠窗口拖拽移动（有“被提起”的轻微抬起/倾斜效果）
- 菜单：点击桌宠上的 `≡`，或在模型上右键/长按打开快捷菜单（聊天/表情/人设/提示词/AI 回复）
- 桌宠聊天：用于“和桌宠单独对话”（不会直接发到主聊天记录）
- AI 回复（填入输入框）：生成一段角色下一句并插入主输入框，便于你再编辑后发送

## 设置项（扩展设置面板）

常用项：
- 启用 VRM Pet
- 为当前角色上传 VRM（上传并绑定 / 清除绑定）
- Overlay size（宽高）
- 桌面走动 / 速度
- 走路摆动 / 强度
- 侧身朝向 / 角度
- 头部追踪、简化眼动
- 空闲动作、眨眼、摸头
- 手臂自然下垂（含模式与幅度）

## 数据存储

- 用户级设置：`ctx.extensionSettings.vrm-pet`
- 角色级数据：写入当前角色 `extensions.vrm-pet`
  - `vrm.url / vrm.storedName / vrm.originalName / vrm.uploadedAt`
  - `petPersona / petSystemPromptExtra`
  - `petChat.messages[]`

## 已知限制 / 兼容性说明

- 走路腿部/膝盖动作是“程序动画 + 轴向自动推断”，不同模型骨骼轴向差异很大；若出现膝盖不弯/反向弯/扭曲，后续可增加“膝盖模式（手动轴向/反向）”兜底
- 渲染兼容性：为了在不同 Three.js / MToon 版本下稳定显示，材质会做兼容降级（例如将不兼容的材质替换为 `MeshBasicMaterial`），因此外观可能与原生 MToon 不完全一致
- 群聊暂不支持：当前逻辑以 `ctx.characterId` 为前提

## 开发备注

- vendor 模块导入带 `?v=`：用于浏览器缓存版本对齐，避免重复模块实例
- `<think>`/`<thinking>`：会在桌宠 UI 和插入主输入框前统一移除，避免把思维链显示到界面
